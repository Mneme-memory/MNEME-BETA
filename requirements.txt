# Installation instructions:
#
# 1. Open Command Prompt (cmd) or PowerShell
#    - Press Win + R
#    - Type "cmd" and press Enter
#
# 2. Navigate to the Mneme project folder:
#    cd C:\path\to\Mneme
#
# 3. Install dependencies:
#    pip install -r requirements.txt
#
# 4. If you get permission errors, try:
#    python -m pip install --user -r requirements.txt
#
# Common issues:
#
# - "pip is not recognized": Python is not in your PATH
#   Solution: Reinstall Python and check "Add to PATH" during installation
#
# - "Could not find a version": You need to update pip
#   Solution: python -m pip install --upgrade pip
#
# - Permission denied: You need admin rights
#   Solution: Right-click Command Prompt → "Run as administrator"
